1. Pendahuluan dan tujuan praktikum

ShopEase merupakan studi kasus aplikasi toko online berbasis CodeIgniter 4. Setelah halaman publik dan navigasi dibuat pada Pertemuan 10, tugas ini menambahkan fondasi autentikasi agar aplikasi dapat membedakan pengunjung, customer, administrator, dan operator toko.

Autentikasi menjawab siapa pengguna yang sedang masuk, sedangkan otorisasi menentukan halaman yang boleh diakses pengguna tersebut. Implementasi memisahkan keduanya melalui AuthController, session, dan AuthFilter.

Tujuan praktikum adalah membangun formulir registrasi dengan validasi, menyimpan password dalam bentuk hash, memverifikasi login, meregenerasi session ID, melakukan redirect sesuai role, melindungi halaman privat, dan mengakhiri session melalui logout.

4. Perancangan tabel users

Struktur tabel mengikuti panduan autentikasi khusus, dengan primary key id_user. Ini berbeda dari contoh id pada beberapa dokumen umum. Penggunaan id_user diterapkan secara konsisten pada migration, model, session, dan query profil.

KolomJenis/logikaKegunaan
id_userINT, primary key, auto incrementIdentitas pengguna.
nameVARCHAR(100), wajibNama tampilan pengguna.
emailVARCHAR(100), unique, wajibIdentitas login; di-trim dan diubah ke huruf kecil sebelum validasi dan penyimpanan.
passwordVARCHAR(255), wajibHash hasil password_hash, bukan password asli.
roleENUM pada MySQL; VARCHAR(20) pada SQLiteNilai customer, admin, atau operator. Registrasi publik menetapkan customer.
phoneVARCHAR(20), nullableNomor telepon opsional.
addressTEXT, nullableAlamat opsional, dibatasi 500 karakter pada validasi aplikasi.
created_at; updated_atDATETIME, timestamp modelWaktu pembuatan dan pembaruan akun.

Index unik pada email melindungi integritas data di tingkat database. Pemeriksaan is_unique memberikan pesan ramah pengguna, sementara constraint database menangani kemungkinan dua request bersamaan. Migration menyesuaikan tipe role berdasarkan driver.

6. Implementasi registrasi customer

  1. Pengguna membuka GET /register.
  2. Form mengirim POST /register bersama token CSRF.
  3. Controller membaca hanya input string, menormalkan nama/email, dan menjalankan validasi server.
  4. Jika tidak valid, server mengembalikan HTTP 422 dan pesan yang sesuai. Password tidak dimasukkan ke nilai lama atau flashdata.
  5. Jika valid, password di-hash dengan password_hash(..., PASSWORD_DEFAULT).
  6. Data disimpan dengan role = customer dan timestamp otomatis.
  7. Server mengarahkan pengguna ke login dengan HTTP 303 dan pesan registrasi berhasil.
InputValidasi
NamaWajib, 3–100 karakter.
EmailWajib, format valid, maksimal 100 karakter, unik setelah normalisasi.
PasswordMinimal 8 karakter, maksimal 72 byte untuk bcrypt, tanpa karakter null.
Konfirmasi passwordWajib dan sama dengan password.
TeleponOpsional; 6–20 karakter berupa angka, spasi, +, -, atau tanda kurung.
AlamatOpsional, maksimal 500 karakter.
RoleTidak tersedia pada form dan tidak diambil dari request publik.

Batas 72 byte diperiksa secara eksplisit agar password multibyte tidak terpotong diam-diam pada bcrypt. Pada error, hanya nama, email, telepon, dan alamat yang dipertahankan di halaman. Semua nilai keluaran di-escape menggunakan esc().

7. Login, session, dan redirect berdasarkan role

Login mencari pengguna berdasarkan email yang telah dinormalisasi, lalu membandingkan password dengan hash menggunakan password_verify(). Email tidak ditemukan maupun password salah menghasilkan pesan yang sama. Setelah autentikasi berhasil, aplikasi menjalankan session()->regenerate(true) untuk mengganti ID session dan membuang session lama.

session()->regenerate(true);
session()->set([
    'isLoggedIn' => true,
    'user_id'    => $user['id_user'],
    'name'       => $user['name'],
    'email'      => $user['email'],
    'role'      => $user['role'],
]);
RoleTujuan setelah loginHalaman khusus
Customer/Profil pribadi di /account.
Admin/adminStatistik jumlah akun dan sepuluh pengguna terbaru.
Operator/operatorIdentitas operator dan tautan katalog.

Pembatasan percobaan menggunakan Throttler dengan token bucket: kapasitas lima percobaan untuk kombinasi email/IP dan 30 untuk IP, dengan pengisian kembali selama 60 detik. Jika kapasitas habis, respons HTTP 429 menyertakan Retry-After. Bucket email/IP dihapus setelah login berhasil.

Cookie session memakai HttpOnly dan SameSite Lax pada lingkungan lokal. Hash diperbarui ketika password_needs_rehash() menyatakan konfigurasi hashing perlu diperbarui. Tampilan login juga menyediakan tombol Lihat/Tutup password yang hanya mengubah jenis input di browser.

Kode lengkap AuthController: registrasi, login, dan logout
<?php
namespace App\Controllers;
use App\Models\UserModel;
use CodeIgniter\HTTP\ResponseInterface;

class AuthController extends BaseController
{
    private function input(string $key): string
    {
        $value = $this->request->getPost($key);
        return is_string($value) && mb_check_encoding($value, 'UTF-8') ? $value : '';
    }
    private function destination(string $role): string
    {
        return ['admin'=>'admin','operator'=>'operator','customer'=>''][$role] ?? '';
    }
    private function form(string $name, array $data = [], int $status = 200): ResponseInterface
    {
        return $this->response->setStatusCode($status)->setBody(view('auth/'.$name, array_merge([
            'title'=>($name === 'login' ? 'Masuk' : 'Daftar').' | ShopEase',
            'page'=>$name, 'errors'=>[], 'values'=>[],
        ], $data)));
    }
    public function register()
    {
        if (session()->get('isLoggedIn')) { return redirect()->to(site_url($this->destination(session('role')))); }
        return $this->form('register');
    }
    public function login()
    {
        if (session()->get('isLoggedIn')) { return redirect()->to(site_url($this->destination(session('role')))); }
        return $this->form('login');
    }
    public function store()
    {
        if (session()->get('isLoggedIn')) { return redirect()->to(site_url($this->destination(session('role')))); }
        $data = [
            'name'=>trim($this->input('name')), 'email'=>strtolower(trim($this->input('email'))),
            'phone'=>trim($this->input('phone')), 'address'=>trim($this->input('address')),
            'password'=>$this->input('password'), 'password_confirm'=>$this->input('password_confirm'),
        ];
        $values = array_intersect_key($data, array_flip(['name','email','phone','address']));
        $rules = [
            'name'=>['rules'=>'required|min_length[3]|max_length[100]', 'errors'=>[
                'required'=>'Nama wajib diisi.','min_length'=>'Nama minimal 3 karakter.','max_length'=>'Nama maksimal 100 karakter.']],
            'email'=>['rules'=>'required|valid_email|max_length[100]|is_unique[users.email]', 'errors'=>[
                'required'=>'Email wajib diisi.','valid_email'=>'Format email tidak valid.',
                'max_length'=>'Email maksimal 100 karakter.','is_unique'=>'Email sudah terdaftar.']],
            'password'=>['rules'=>'required|min_length[8]|max_length[72]', 'errors'=>[
                'required'=>'Password wajib diisi.','min_length'=>'Password minimal 8 karakter.','max_length'=>'Password terlalu panjang.']],
            'password_confirm'=>['rules'=>'required|matches[password]', 'errors'=>[
                'required'=>'Konfirmasi password wajib diisi.','matches'=>'Konfirmasi password tidak sama.']],
            'phone'=>['rules'=>'permit_empty|regex_match[/^[0-9+() -]{6,20}$/]', 'errors'=>[
                'regex_match'=>'Nomor telepon harus 6–20 karakter: angka, spasi, +, -, atau tanda kurung.']],
            'address'=>['rules'=>'permit_empty|max_length[500]', 'errors'=>['max_length'=>'Alamat maksimal 500 karakter.']],
        ];
        $valid = $this->validateData($data,$rules);
        $errors = $this->validator->getErrors();
        // Bcrypt PASSWORD_DEFAULT dibatasi 72 byte; hindari pemotongan diam-diam.
        if (strlen($data['password']) > 72 || str_contains($data['password'], "\0")) {
            $errors['password'] = 'Password maksimal 72 byte dan tidak boleh mengandung karakter null.';
        }
        if (!$valid || $errors) { return $this->form('register',compact('values','errors'),422); }
        $model = new UserModel();
        try {
            $saved = $model->insert([
                'name'=>$data['name'],'email'=>$data['email'],
                'password'=>password_hash($data['password'],PASSWORD_DEFAULT),
                'role'=>'customer', // Tidak mengambil role dari formulir/request.
                'phone'=>$data['phone'] ?: null, 'address'=>$data['address'] ?: null,
            ]);
            if ($saved === false) { throw new \RuntimeException('Insert user gagal.'); }
        } catch (\Throwable $e) {
            // Index unik menangani dua registrasi email yang sama secara bersamaan.
            if ($model->where('email',$data['email'])->first()) {
                return $this->form('register',['values'=>$values,'errors'=>['email'=>'Email sudah terdaftar.']],422);
            }
            log_message('error','Registrasi gagal: {message}', ['message'=>$e->getMessage()]);
            return $this->form('register',['values'=>$values,'errors'=>['database'=>'Registrasi belum dapat disimpan. Coba lagi.']],500);
        }
        return redirect()->to(site_url('login'))->with('success','Registrasi berhasil. Silakan login.');
    }
    public function authenticate()
    {
        if (session()->get('isLoggedIn')) { return redirect()->to(site_url($this->destination(session('role')))); }
        $email = strtolower(trim($this->input('email')));
        $password = $this->input('password');
        $values = ['email'=>$email];
        if (!$this->validateData(compact('email','password'),[
            'email'=>['rules'=>'required|valid_email|max_length[100]','errors'=>[
                'required'=>'Email wajib diisi.','valid_email'=>'Format email tidak valid.','max_length'=>'Email terlalu panjang.']],
            'password'=>['rules'=>'required','errors'=>['required'=>'Password wajib diisi.']],
        ])) { return $this->form('login',['values'=>$values,'errors'=>$this->validator->getErrors()],422); }
        $throttle = service('throttler');
        $ipKey = 'login_ip_'.hash('sha256',$this->request->getIPAddress());
        $accountKey = 'login_account_'.hash('sha256',$email.'|'.$this->request->getIPAddress());
        // Token bucket: 5 percobaan per kombinasi akun/IP; terisi ulang selama 60 detik.
        if (!$throttle->check($ipKey,30,60) || !$throttle->check($accountKey,5,60)) {
            $wait = max(1,$throttle->getTokenTime());
            $this->response->setHeader('Retry-After',(string)$wait);
            return $this->form('login',['values'=>$values,'errors'=>['login'=>"Terlalu banyak percobaan. Coba lagi dalam {$wait} detik."]],429);
        }
        $model = new UserModel();
        $user = $model->where('email',$email)->first();
        // Hash dummy menghindari jalur tanpa password_verify untuk email yang tidak ditemukan.
        $hash = $user['password'] ?? '$2y$12$92IXUNpkjO0rOQ5byMi.Ye4oKoEa3Ro9llC/.og/at2uheWG/igi.';
        $matches = strlen($password) <= 72 && !str_contains($password,"\0") && password_verify($password,$hash);
        if (!$user || !$matches || !in_array($user['role'],['customer','admin','operator'],true)) {
            return $this->form('login',['values'=>$values,'errors'=>['login'=>'Email atau password salah.']],401);
        }
        if (password_needs_rehash($user['password'],PASSWORD_DEFAULT)) {
            $model->update($user['id_user'],['password'=>password_hash($password,PASSWORD_DEFAULT)]);
        }
        $throttle->remove($accountKey);
        session()->regenerate(true);
        session()->set([
            'isLoggedIn'=>true,'user_id'=>$user['id_user'],'name'=>$user['name'],
            'email'=>$user['email'],'role'=>$user['role'],
        ]);
        return redirect()->to(site_url($this->destination($user['role'])))->with('success','Login berhasil. Selamat datang di ShopEase.');
    }
    public function logout()
    {
        session()->destroy();
        // Jangan menulis flashdata ke session yang sudah dihancurkan.
        return redirect()->to(site_url('login').'?logout=1');
    }
}

8. Routing, AuthFilter, dan proteksi CSRF

Auto Routing dinonaktifkan sehingga endpoint hanya tersedia melalui rute yang didefinisikan. Filter auth:admin dan auth:operator diterapkan pada grup rute masing-masing. Profil memakai auth:customer.

Kode lengkap Routes.php
<?php
use CodeIgniter\Router\RouteCollection;
/** @var RouteCollection $routes */
$routes->setAutoRoute(false);
$routes->get('/', 'HomeController::index', ['as'=>'home']);

$routes->get('about', 'HomeController::about', ['as'=>'about']);
$routes->get('contact', 'HomeController::contact', ['as'=>'contact']);

$routes->get('login', 'AuthController::login', ['as'=>'login']);

AuthFilter membaca ulang akun dari database pada setiap akses privat. Karena itu perubahan role berlaku pada request berikutnya, dan akun yang dihapus tidak dapat mempertahankan akses hanya melalui session lama. Role yang tidak sesuai mendapatkan halaman 403 dengan tautan kembali ke area akun.

Kode lengkap AuthFilter
<?php
namespace App\Filters;
use App\Models\UserModel;
use CodeIgniter\Filters\FilterInterface;
use CodeIgniter\HTTP\RequestInterface;
use CodeIgniter\HTTP\ResponseInterface;

class AuthFilter implements FilterInterface
{
    public function before(RequestInterface $request, $arguments = null)
    {
        helper('url');
        $session = session();
        if (!$session->get('isLoggedIn')) {
            return redirect()->to(site_url('login'))->with('error','Silakan login terlebih dahulu.');
        }
        // Baca ulang akun: perubahan role/penghapusan akun berlaku pada request berikutnya.
        $user = (new UserModel())->find($session->get('user_id'));
        if (!$user || !in_array($user['role'], ['customer','admin','operator'], true)) {
            $session->destroy();
            return redirect()->to(site_url('login'));
        }
        $session->set(['name'=>$user['name'],'email'=>$user['email'],'role'=>$user['role']]);
        if ($arguments && !in_array($user['role'], $arguments, true)) {
            return service('response')->setStatusCode(403)->setBody(view('auth/forbidden',[
                'title'=>'Akses ditolak | ShopEase', 'page'=>'account',
            ]));
        }
    }
    public function after(RequestInterface $request, ResponseInterface $response, $arguments = null) {}
}

12. Cara menjalankan dan mendemonstrasikan hasil

  1. Buka folder repository di VS Code, masuk ke Tugas/Tugas Pertemuan 11, lalu jalankan setup SQLite.
  2. Jalankan php spark serve dari folder shopease pada Terminal biasa.
