1. Pendahuluan

Pada pertemuan ini, saya membuat halaman awal ShopEase, sebuah studi kasus toko online berbasis CodeIgniter 4. Pengunjung perlu mengetahui jenis produk yang tersedia dan menemukan katalog dari halaman pertama. Karena itu, saya menempatkan banner dan tombol menuju katalog di bagian atas, lalu menampilkan kategori serta produk pilihan di bawahnya.

Tujuan praktikum ini adalah menghubungkan URL ke method yang tepat, menyiapkan data pada controller, dan merender halaman dengan view. Saya juga menggunakan satu layout bersama agar navigasi dan footer konsisten di seluruh halaman.

Ruang lingkup pengerjaan mengikuti tugas Pertemuan 10 yang diberikan di kelas dan bagian Routing, Controller, dan View pada Hands-On Lab. Kebutuhan toko lengkap seperti akun, keranjang, checkout, pembayaran, pengiriman, dan panel admin merupakan modul lanjutan dalam PRD.

3. Persiapan dan cara menjalankan

  • Perangkat. MacBook Pro 2020 Intel Core i5, RAM 8 GB, penyimpanan 256 GB, macOS Sequoia 15.8.2.
  • Runtime. PHP 8.4.12 yang sudah tersedia di Terminal. CodeIgniter 4.7.6 memerlukan PHP 8.2 atau lebih baru dan ekstensi intl serta mbstring.
  • Framework dan tampilan. CodeIgniter 4.7.6 dari paket instalasi manual dan Bootstrap 5.3.3 dari aset lokal. CSS khusus mengatur warna, tipografi, dan susunan halaman. SVG lokal digunakan untuk logo serta ilustrasi produk.
  • Editor dan browser. Visual Studio Code untuk membaca atau mengubah kode, serta Safari atau Chrome untuk membuka aplikasi.

Folder proyek sudah menyertakan system/ dan aset Bootstrap, sehingga demo dapat dijalankan langsung dengan PHP. Dari direktori repositori PBKK---C, buka Terminal dan jalankan perintah berikut.

cd "Tugas/Tugas Pertemuan 10/shopease"
php -v
php --ri intl
php --ri mbstring
php spark routes
php spark serve

Selama server aktif, buka http://localhost:8080/ di browser. Tekan Control+C di Terminal untuk menghentikannya. Gunakan server pengembangan ini untuk demonstrasi lokal.

Jika port 8080 sedang dipakai, buat .env dari env apabila belum ada. Atur app.baseURL = 'http://localhost:8081/', jalankan php spark serve --port 8081, lalu buka http://localhost:8081/.

5. Implementasi routing, controller, dan view

5.1 Routing

Di app/Config/Routes.php, saya mengganti rute halaman sambutan bawaan dengan empat rute GET. Alias seperti catalog digunakan oleh url_to() untuk membangun tautan dari layout dan tombol. Nilai indexPage di app/Config/App.php dikosongkan agar tautan menggunakan URL seperti /about.

$routes->get('/', 'HomeController::index', ['as' => 'home']);
$routes->get('catalog', 'HomeController::catalog', ['as' => 'catalog']);
$routes->get('about', 'HomeController::about', ['as' => 'about']);
$routes->get('contact', 'HomeController::contact', ['as' => 'contact']);
URLMethod controllerView
/HomeController::indexfrontend/home.php
/catalogHomeController::catalogfrontend/catalog.php
/aboutHomeController::aboutfrontend/about.php
/contactHomeController::contactfrontend/contact.php

5.2 Controller dan sumber data

HomeController mewarisi BaseController. Method index() membaca kategori dan produk dari DemoCatalog, mengambil produk untuk banner, lalu membagi data menurut koleksi. Method about() dan contact() memasok judul dan penanda halaman aktif. Method contact() juga mengirim alamat email demo ke view.

public function contact(): string
{
    return view('frontend/contact', [
        'title' => 'Kontak | ShopEase',
        'page' => 'contact',
        'email' => 'halo@shopease.example',
    ]);
}

Pada catalog(), controller membaca parameter q dan kategori dari permintaan GET. Kata kunci dibatasi 80 karakter. Kategori dicocokkan dengan daftar slug yang tersedia. mb_stripos() mencari kata kunci pada nama dan deskripsi tanpa membedakan kapitalisasi. Jika keduanya diisi, produk harus memenuhi kedua kondisi.

$matchesCategory = $category === '' || $product['category'] === $category;
$searchText = $product['name'] . ' ' . $product['description'];

return $matchesCategory
    && ($query === '' || mb_stripos($searchText, $query, 0, 'UTF-8') !== false);

DemoCatalog adalah kelas data contoh yang memuat empat kategori dan delapan produk. Setiap produk mempunyai nama, deskripsi, kategori, harga, berkas ilustrasi, dan penanda koleksi. Pada aplikasi penuh, data ini dapat berasal dari model yang membaca tabel produk dan kategori di MySQL.

5.3 View, layout, dan desain responsif

Setiap halaman menggunakan extend('layouts/store') dan menaruh isi utamanya di section content. Layout menyisipkan section tersebut melalui renderSection('content'). Judul, navigasi, footer, dan pemanggilan CSS ditulis sekali. Beranda dan katalog juga menggunakan ulang product_grid.php untuk kartu produk.

<title><?= esc($title) ?></title>
<main id="main-content" tabindex="-1">
    <?= $this->renderSection('content') ?>
</main>

Grid Bootstrap row-cols-2 row-cols-lg-4 membuat kartu menjadi dua kolom pada layar sempit dan empat kolom mulai dari ukuran lg. CSS menumpuk teks serta ilustrasi banner pada layar sempit. Form katalog memiliki label pada setiap input. Navigasi aktif ditandai dengan aria-current dan FAQ menggunakan elemen HTML details.

base_url() membentuk alamat aset lokal. esc() mengubah karakter khusus pada data keluaran agar browser membacanya sebagai teks, termasuk saat nilai pencarian ditampilkan kembali. Harga disusun dengan pemisah ribuan titik melalui number_format().

6. Alur dan hasil demonstrasi

Alur permintaan
Browser meminta URL → CodeIgniter mencocokkan rute → controller menyiapkan data → view mengisi layout → browser menerima HTML.

  1. Buka Beranda. Banner menampilkan ilustrasi headphone dengan tombol Lihat katalog. Di bawahnya terdapat empat kategori, empat produk terbaru, dan empat produk terlaris.
  2. Klik kategori Elektronik. Alamat menjadi /catalog?kategori=elektronik dan kartu Headphone Aura X1 serta Keyboard Nova 68 ditampilkan.
  3. Klik Reset pencarian, masukkan lampu, lalu tekan Cari. Hasilnya adalah Lampu Meja Luma. Untuk kata kunci yang tidak cocok, katalog menampilkan pesan dan tombol kembali ke semua produk.
  4. Buka Tentang untuk melihat peran customer, administrator, dan operator toko dalam PRD. Buka Kontak untuk melihat informasi email contoh dan FAQ.

Pada desktop, teks dan ilustrasi banner berdampingan. Pada pratinjau 390 piksel, isi banner dan form katalog tersusun vertikal. Pratinjau Kontak pada 320 piksel menempatkan kartu email dan FAQ dalam satu kolom.

7. Pengujian

Sintaks file PHP yang dibuat atau diubah diperiksa dengan php -l. Daftar rute diperiksa dengan php spark routes. Karena sesi pengujian membatasi pembukaan port lokal, respons public/index.php diuji melalui PHP CGI 8.4.12. Tampilan diperiksa di Safari dari HTML hasil respons tersebut.
